# Olá, eu sou o Fábio (IRPF Trader) 👋

Focado em unir tecnologia e mercado financeiro para simplificar a vida do investidor brasileiro. 

### 🎯 O que eu faço
Desenvolvo ferramentas e automações que transformam dados complexos da B3 em informações úteis para o controle de investimentos e conformidade fiscal (IRPF).

### 🚀 Projetos Principais
- **[darf6015](https://www.darf6015.com.br):** Soluções para cálculo e gestão de impostos para traders.
- **Planilhas de Cotações:** Automações em tempo real para monitoramento de ativos (IBOV, SMLL).
- **Gestão Financeira:** Dashboards para controle de gastos mensais.
